# 조사 방법과 한계

## 1차 조사 (2026-11-07)

**방식.** 지역·주제별 리서치 에이전트 8개를 동시에 돌렸습니다. 각 에이전트는 웹 검색으로 후보를 찾고 구글 평점을 확인한 뒤,
`research/raw/<이름>.json`(구조화 데이터)과 `research/raw/<이름>-notes.md`(조사 노트·출처·제외 사유)를 남겼습니다.

| 원자료 | 범위 |
|---|---|
| `fnb-belgisches-friesen` | 벨기에 지구, 프리젠 지구·에렌슈트라세 식음료 |
| `fnb-dom-altstadt-eigelstein` | 대성당·구시가, 아그네스 지구·아이겔슈타인 식음료 + 쾰시·브라우하우스 문화 |
| `fnb-deutz-messe` | 도이츠·쾰른 메쎄 주변 식음료 + 메쎄 방문자 메모 |
| `fnb-ehrenfeld-lateng` | 에렌펠트, 크바르티어 라텡 식음료 |
| `fnb-suedstadt-other-korean` | 쥐트슈타트·라인아우하펜, 기타 지역, 한식당, 미쉐린 2026 전체 목록 |
| `bars` | 시내 바 + World's 50 Best Bars 확인 |
| `wine-*` | 독일 화이트와인 가이드, 쾰른 와인바·와인숍 |
| `attractions` | 관광지, 시즌 이벤트, 근교 당일치기 |

**구글 평점 확인.** 구글 지도 수치를 그대로 보여 주는 집계 사이트(werkenntdenbesten.de — 기준일 표시, restaurantguru.com,
spinach.guide, wanderlog.com 등)를 검색해 평점·리뷰 수·출처·기준일을 기록했습니다. 추정하거나 기억에 의존한 수치는 쓰지 않았습니다.

**포함 기준.** 구글 평점 4.2 이상, 리뷰 50개 이상, 폐업 신호 없음. 수치의 출처 귀속이 애매하면(`confidence: low`)
기준을 넘어도 후보로 보냈습니다(예: Café Feynsinn — 4.2라는 수치가 구글 것인지 불분명).

## 한계

1. **검색 한도.** 웹 검색은 한 번의 요청당 200회이고 모든 에이전트가 나눠 씁니다. 1차 조사에서는 후보 발굴에 대부분을 쓰는 바람에
   평점까지 확인한 곳이 12곳뿐이고, 나머지 125곳은 주소·특징·출처만 있는 후보 상태입니다.
2. **집계 사이트 수치는 실시간이 아닙니다.** 기준일이 몇 달 전인 경우가 있습니다. 방문 전 구글 지도에서 다시 확인하세요.
   `scripts/verify_google_places.py`에 Google Places API 키를 넣으면 전체를 실시간 값으로 갱신할 수 있습니다.
3. **웹 페이지 직접 열람과 지오코딩이 막혀 있습니다.** 이 작업 환경의 네트워크 정책 때문에 검색 결과 요약만 쓸 수 있었고,
   OpenStreetMap Nominatim(주소 → 좌표)에 접근하지 못해 좌표가 비어 있습니다. 그래서 거리 필터·거리순 정렬은 좌표를 채운 뒤 켜집니다.
4. **후보 주소 일부는 미검증입니다.** 노트에 "주소 미확인/사전 지식"으로 표시된 주소는 2차 조사에서 확인합니다.

## 2차 조사 계획 (1차 종료 시점)

1. 후보 125곳의 구글 평점·리뷰 수 확인(1곳당 검색 1회) → 기준 충족 시 본 목록으로
2. 빈 곳 채우기: 프리젠 지구·에렌슈트라세, 대성당 근처 카페·아침, 한식당, 칵테일바 시드(Shepheard, Spirits Bar 등), 크래프트 맥주 바
3. 메쎄 방문자 정보 검증(입구·교통·2026년 11월–2027년 4월 전시 일정)
4. 좌표 채우기(`scripts/geocode.py`) → 거리 필터 활성화

## 2차 조사 (2026-11-07) — 세계 음식 확대 + 분류 v2

**요청.** "꼭 독일 요리일 필요는 없다, 다른 나라 요리를 더 분석하고 분류를 개선해 달라."

**방식.** 요리 문화권별 에이전트 6개(동아시아 · 동남아·남아시아 · 중동·터키·아프리카 · 유럽·아메리카 · 카페·디저트 · 바)를 돌리고,
관광지 후보는 리드가 직접 10회 검색으로 확인했습니다. 검색 한도가 다시 바닥나지 않도록 에이전트마다 상한(20–30회)을 두었고,
Wanderlog처럼 한 페이지에 여러 곳의 구글 평점·리뷰 수·주소가 나오는 목록형 검색을 먼저 한 뒤 빈 곳만 개별 검색했습니다.
각 에이전트는 1차 후보를 먼저 검증하고 새 곳을 발굴했습니다(`research/raw/r2-*.json`, `r2-*-notes.md`).

**분류 v2.** 나라·스타일이 섞여 있던 `cuisine_group`을 나라(ISO 코드) + 문화권, 요리, 식단, 시간대, 상황, 공간·서비스, 음료,
분위기, 예약, 결제, 1인 가격대로 나눴습니다. 1차 데이터는 import 때 자동 변환됩니다(`scripts/schema.py`의 `V1_TAGS`, `V1_CUISINE_GROUP`).

**결과.** 기준 충족 식당 99곳 + 카페·디저트 26곳(30개 나라), 바 14곳, 관광지 60곳, 후보 202곳.

**새로 생긴 한계.**
- Wanderlog·top-rated.online 같은 출처는 구글 수치의 기준일을 보여 주지 않아 대부분 `google_as_of`가 비어 있고 `confidence: medium`입니다.
- 가격대 출처가 드물어, 카페·간편식·디저트·브라우하우스·파인다이닝은 유형 기준 추정값(`price_estimated: true`, 뷰어에 "추정")을 넣었습니다.
  일반 레스토랑 67곳은 추정하지 않고 비워 두었습니다.
- 검색 한도는 사용자 메시지 한 번(한 턴)마다 새로 생깁니다. 이전 턴에 시작한 에이전트는 새 한도를 쓰지 못했습니다.
- 중복 처리: 같은 곳이 여러 파일에 있으면 나중 조사(r2-*)가 우선하고, 같은 지역 안의 이름 변형(예: Oruc / Oruç Kebap)도 하나로 합칩니다.

## 좌표 (2026-11-07)

이 레포 전용 클라우드 환경(koln-guide)에서 `nominatim.openstreetmap.org`를 허용한 뒤 `scripts/geocode.py`로 199곳의 주소를 좌표로 바꿨습니다
(초당 1회 이하, 결과는 `data/geocode-cache.json`에 캐시). 지역 중심에서 너무 먼 점을 검사했고, 퍼레이드 경로처럼 한 점이 아닌 주소는
좌표를 비워 둡니다(`schema.is_area_wide`). 거리는 직선거리이고 도보 시간은 우회 1.3배·시속 4.8km 어림값입니다.
지도 데이터 © OpenStreetMap contributors (ODbL).

## 4차: 정확도 재확인 (2026-11-07)

본 목록 161곳을 지역별 5개 묶음으로 나눠 곳마다 웹 검색으로 영업 여부, 구글 수치, 1인 가격대, 최근 리뷰 시점, 주소를 다시 확인했습니다.
결과는 `research/raw/r4-verify-*.json`에 두고 import 때 덧씌웁니다(폐업·임시휴업은 후보로 이동, 더 최신 구글 수치와 가격대 반영,
주소가 바뀌면 좌표를 다시 계산). 사진은 검색 도구로 볼 수 없어 최근 리뷰 시점을 활동 신호로 썼습니다. 요약은
[`verification-2026-11-07.md`](verification-2026-11-07.md). 구글 Places API 연동은 사용자가 키를 주지 않아 보류했고,
`scripts/verify_google_places.py`는 키가 생기면 place ID만 저장하고 평점 등은 변경 내역만 출력하도록 바꿨습니다(구글 약관의 캐싱 제한).

## 러닝 코스 (2026-11-07)

공개 장소만 경유지로 쓰고(출발·도착: 프리젠플라츠), OpenStreetMap 보행 경로 서버(routing.openstreetmap.de)로 실제 길을 계산했습니다.
`data/routes-spec.json`(경유지 정의) → `scripts/build_routes.py` → `routes/*.kml|gpx|geojson`, `data/routes.json`(뷰어용 단순화 경로·1km 표시·구글 지도 링크).
구글 지도 길찾기 링크는 경유지 9곳 제한 때문에 긴 코스를 두 구간으로 나눴습니다. 일출·일몰은 NOAA 근사식으로 계산했습니다.

## 5차: 입장권·운영시간 (2026-11-07)

관광지를 세 묶음(대성당·시립 박물관 / 민간 박물관·체험 / 성당·크리스마스 마켓·공원)으로 나눠 묶음마다 웹 검색 24–26회로
박물관·성당·시설 **공식 사이트**를 우선 확인했습니다. 기록 항목: 입장권 목록(성인·할인·어린이·가족·콤비와 조건), 2026년 11–12월
요일별 운영시간, 마지막 입장, 무료 조건, 예약 필요 여부·공식 예매 링크, 운영 상태, 출처, 확인 시점, 신뢰도
(high = 공식 2026 / medium = 공식이지만 날짜 미표기 또는 신뢰할 만한 2차 출처 / low = 참고용).
결과는 `research/raw/r5-tickets-{dom-city,private,churches-markets}.json`의 `updates`(기존 관광지)와 `places`(새 관광지 5곳:
동아시아 미술관, 쾰른 동물원, KD 파노라마 유람선, 플로라·식물원, 멜라텐 묘지)에 있고, import 때 기존 항목에 덧씌웁니다.

- 조사 노트에 공식 출처로 적힌 특정 날짜 일정(토텐존탁 11/22, 성탄·연말 휴관, 첫째 목요일 야간 개관, 전시 교체 휴관)은
  `research/raw/r5-tickets-dates.json`에 날짜별 예외(`date_hours`)로 옮겼습니다. 새 사실은 넣지 않았고, 연도 표기가 없는 공식 일정은
  메모에 그렇게 적었습니다. 2016/17년 공지처럼 오래된 것은 넣지 않았습니다.
- 출처끼리 다르면 공식 쪽을 쓰고 차이를 메모에 남겼습니다(예: 루트비히 €15.40 vs €13.50, 초콜릿 박물관 가족권, KD 어린이 요금).
- 웹 뷰어는 쾰른 시각(Europe/Berlin)으로 오늘의 운영 여부를 계산합니다. 시즌 밖이면 "개막 전/끝남", 날짜 예외가 있으면 그날 시간,
  12/24–26·31·1/1에 따로 안내가 없으면 "시간이 다를 수 있어요"를 붙입니다. 유람선·지붕 투어는 '지금 열림' 대신 회차를 보여 줍니다.
- 남은 공백: 대성당 내부와 성당 7곳의 성탄·연말 시간, 성당 4곳의 입장료 여부, KölnTriangle 운영사의 2026 공지, 동물원·4711의
  연말 시간, 뮤지엄카드 참여관 전체 목록. Odysseum은 2025년에 문을 닫아 넣지 않았습니다.
- 동물원 주소 검색이 근처 카페로 잡혀 OSM의 동물원 객체 좌표로 바꿨습니다(`data/geocode-cache.json`의 note).

## 6차: 스타일·가격대 (2026-11-07)

- **스타일**(비스트로·와인바·타파스·이자카야·피자리아…): 영문 설명(`cuisine`)과 이름에서 규칙으로 자동 분류하고(`scripts/schema.py`
  `STYLE_RULES`·`infer_style`), 가격 조사에서 출처가 분명히 그렇게 부르면(`style_hint`) 그것을 씁니다. 157곳 중 127곳에 스타일이
  붙고, 나머지는 "레스토랑"으로 나라와 함께 보여 줍니다. 규칙 결과는 157곳 전부를 눈으로 검토해 잘못 걸린 경우(예: Espressobar의
  "soba", 팬아시안 식당의 "noodle")를 고쳤습니다.
- **가격대**: 가격 정보가 없던 75곳을 세 묶음으로 나눠 웹 검색 125회로 조사했습니다(메뉴판, speisekarte.de, 배달 앱 메뉴, OpenTable·
  레스토랑구루 1인 범위, 지역 매체). 49곳에 가격대를 넣었고, 배달 앱 가격·오래된 메뉴·가격 등급 기호만 있는 경우는 신뢰도 low로
  두어 뷰어에 "약"으로 표시합니다. 결과는 `research/raw/r6-price-{a,b,c}.json`. 동네 펍 10곳의 쾰시 가격과 일부 칵테일바·레스토랑
  26곳은 출처를 찾지 못해 비워 뒀습니다(폐업 신호는 없음).
- 이제 157곳 중 131곳에 가격대가 있고, 그중 55곳은 유형 기준 추정이거나 근거가 약한 값입니다.
- 지도 아래 목록·지도 카드·목록 카드에 가격대, 나라, 스타일, 대표 메뉴(조사된 `must_try`의 한국어 이름, 없으면 요리 분류)를 보여 주고,
  "스타일" 필터와 검색(예: "타파스", "와인바")을 추가했습니다.

## 7차: 벨기에 지구 집중 — 독일·쾰른 요리, 와인바, 바·라운지 (2026-11-07)

세 묶음(독일·쾰른 요리 / 와인바 / 활기찬 바·라운지)으로 나눠 웹 검색 134회로 조사했습니다. 기준은 같습니다(구글 ★4.2+ · 리뷰 50+,
