# 조사 방법과 한계

## 1차 조사 (2026-11-07)

**방식.** 지역·주제별 리서치 에이전트 8개를 동시에 돌렸습니다. 각 에이전트는 웹 검색으로 후보를 찾고 구글 평점을 확인한 뒤,
`research/raw/<이름>.json`(구조화 데이터)과 `research/raw/<이름>-notes.md`(조사 노트·출처·제외 사유)를 남겼습니다.

| 원자료 | 범위 |
|---|---|
| `fnb-belgisches-friesen` | 벨기에 지구, 프리젠 지구·에렌슈트라세 식음료 |
| `fnb-dom-altstadt-eigelstein` | 대성당·구시가, 아그네스 지구·아이겔슈타인 식음료 + 쾰시·브라우하우스 문화 |
| `fnb-deutz-messe` | 도이츠·쾰른 메쎄 주변 식음료 + 메쎄 방문자 메모 |
| `fnb-ehrenfeld-lateng` | 에렌펠트, 크바르티어 라텡 식음료 |
| `fnb-suedstadt-other-korean` | 쥐트슈타트·라인아우하펜, 기타 지역, 한식당, 미쉐린 2026 전체 목록 |
| `bars` | 시내 바 + World's 50 Best Bars 확인 |
| `wine-*` | 독일 화이트와인 가이드, 쾰른 와인바·와인숍 |
| `attractions` | 관광지, 시즌 이벤트, 근교 당일치기 |

**구글 평점 확인.** 구글 지도 수치를 그대로 보여 주는 집계 사이트(werkenntdenbesten.de — 기준일 표시, restaurantguru.com,
spinach.guide, wanderlog.com 등)를 검색해 평점·리뷰 수·출처·기준일을 기록했습니다. 추정하거나 기억에 의존한 수치는 쓰지 않았습니다.

**포함 기준.** 구글 평점 4.2 이상, 리뷰 50개 이상, 폐업 신호 없음. 수치의 출처 귀속이 애매하면(`confidence: low`)
기준을 넘어도 후보로 보냈습니다(예: Café Feynsinn — 4.2라는 수치가 구글 것인지 불분명).

## 한계

1. **검색 한도.** 웹 검색은 한 번의 요청당 200회이고 모든 에이전트가 나눠 씁니다. 1차 조사에서는 후보 발굴에 대부분을 쓰는 바람에
   평점까지 확인한 곳이 12곳뿐이고, 나머지 125곳은 주소·특징·출처만 있는 후보 상태입니다.
2. **집계 사이트 수치는 실시간이 아닙니다.** 기준일이 몇 달 전인 경우가 있습니다. 방문 전 구글 지도에서 다시 확인하세요.
   `scripts/verify_google_places.py`에 Google Places API 키를 넣으면 전체를 실시간 값으로 갱신할 수 있습니다.
3. **웹 페이지 직접 열람과 지오코딩이 막혀 있습니다.** 이 작업 환경의 네트워크 정책 때문에 검색 결과 요약만 쓸 수 있었고,
   OpenStreetMap Nominatim(주소 → 좌표)에 접근하지 못해 좌표가 비어 있습니다. 그래서 거리 필터·거리순 정렬은 좌표를 채운 뒤 켜집니다.
4. **후보 주소 일부는 미검증입니다.** 노트에 "주소 미확인/사전 지식"으로 표시된 주소는 2차 조사에서 확인합니다.

## 2차 조사 계획

1. 후보 125곳의 구글 평점·리뷰 수 확인(1곳당 검색 1회) → 기준 충족 시 본 목록으로
2. 빈 곳 채우기: 프리젠 지구·에렌슈트라세, 대성당 근처 카페·아침, 한식당, 칵테일바 시드(Shepheard, Spirits Bar 등), 크래프트 맥주 바
3. 메쎄 방문자 정보 검증(입구·교통·2026년 11월–2027년 4월 전시 일정)
4. 좌표 채우기(`scripts/geocode.py`) → 거리 필터 활성화
